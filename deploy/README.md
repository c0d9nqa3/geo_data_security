# deploy：Windows部署目录

## 模块定位

本目录用于保存两台Windows服务器和终端环境的安装、初始化、启动、停止、检查、备份与恢复说明。

## 计划目录

- `server1/`：服务器1应用、配置和服务管理。
- `server2/`：服务器2数据、安全和处理服务管理。
- `terminal/`：终端浏览器访问、证书、网络和客户端说明。
- `firewall/`：端口白名单和访问矩阵模板，最终由甲方网络管理员执行。
- `offline/`：涉密网离线安装包清单和依赖校验记录。

## 当前部署原则

- 测试环境允许使用远程桌面进行安装和联调。
- 生产环境使用内网交换机或甲方批准的安全网络设备。
- 测试IP、生产IP、密码和证书不得写入代码仓库。
- 服务端口必须由配置文件注入。
- 部署完成后必须验证终端上传只能到服务器1，终端结果读取只能走服务器2只读接口。
