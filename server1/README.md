# server1：数据接入与业务控制服务器

## 模块定位

服务器1是终端上传数据和提交处理请求的唯一业务接收入口。它负责身份、权限和流程控制，不负责执行大型测绘数据算法，也不直接向终端暴露服务器2的原始数据。

## 模块顺序

组装入口：`app/`（唯一 Spring Boot 启动类，打包部署这一个 fat jar）。

1. `gateway/`：对终端开放的接入层：鉴权、限流、统一错误（库模块，无启动类）。
2. `auth/`：登录、令牌、用户、角色。
3. `circulation/`：流转申请、审核、服务器2结果授权协作。
4. `ingest/`：终端数据接收（文件管理：上传、校验、转交索引）。
5. `project/`：项目、成员和项目状态。
6. `task/`：创建任务、提交服务器2、查询任务状态。
7. `audit/`：业务审计事件产生、提交与追溯查询。

支撑模块：`common/`（统一响应）、`web/`（终端 Web 界面）。

## 启动

```bash
cd server1
mvn clean install -DskipTests
mvn -pl app spring-boot:run
```

默认端口 `8081`。前端 Vite 把 `/api` 代理到该端口。

## 访问边界

终端可以访问服务器1的登录、上传、项目、任务、流转和状态接口。终端不能通过服务器1读取服务器2的原始数据，也不能访问数据库或服务器文件系统。

## 与服务器2的关系

服务器1只通过内部受控接口向服务器2转交已授权的数据和任务，并接收任务状态、结果索引和链上凭证。
