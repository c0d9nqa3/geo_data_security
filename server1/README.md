# server1：数据接入与业务控制服务器

## 模块定位

服务器1是终端上传数据和提交处理请求的唯一业务接收入口。它负责身份、权限和流程控制，不负责执行大型测绘数据算法，也不直接向终端暴露服务器2的原始数据。

## 计划模块

- `gateway/`：服务器1对终端开放的业务API入口和请求路由。
- `auth/`：登录、令牌、用户、角色和项目权限。
- `project/`：项目、成员和项目状态管理。
- `ingest/`：接收终端上传的数据，做大小、格式、哈希和基础检查。
- `task/`：创建任务、提交服务器2、查询任务状态。
- `circulation/`：流转申请、审核状态和服务器2结果授权协作。
- `audit/`：记录服务器1侧的业务审计事件。
- `web/`：终端使用的Web管理界面。

## 访问边界

终端可以访问服务器1的登录、上传、项目、任务和状态接口。终端不能通过服务器1读取服务器2的原始数据，也不能访问数据库或服务器文件系统。

## 与服务器2的关系

服务器1只通过内部受控接口向服务器2转交已授权的数据和任务，并接收任务状态、结果索引和链上凭证。接口必须使用服务身份认证、请求签名或内部令牌，不能使用终端用户令牌直接代替服务身份。
