# server1 服务程序

服务器1程序的源码目录。当前按模块化单体组织，后续可以在不改变接口的前提下拆分服务。

目录职责：

- `gateway/`：终端业务接入和路由。
- `auth/`：身份、角色、项目权限。
- `project/`：项目和成员管理。
- `ingest/`：终端上传接收、校验和转交。
- `task/`：任务创建、调度、状态。
- `circulation/`：审批和流转控制。
- `audit/`：服务器1业务审计。
- `web/`：前后端分离的前端工程（Vue），浏览器终端界面；只通过 REST 调 gateway 等模块。

组织方式：模块化单体 + 前后端分离。`web` 与 `auth/gateway/project/...` 同属服务器1仓库树，但构建与接口契约分离，便于后续调用服务器2。

不在本目录实现水印算法、沙箱执行器和原始数据存储。
