# 架构冻结决议

## 已确定的业务方向

```text
终端上传数据/提交请求 → 服务器1
服务器1转交数据/任务 → 服务器2
服务器2完成计算/水印/审核 → 服务器2
终端获取审核通过结果 → 服务器2只读结果接口
```

## 两台服务器职责

### 服务器1

数据接入、身份认证、权限控制、项目管理、任务管理、上传校验、服务器间任务转交、状态查询和业务流程控制。

### 服务器2

项目加密存储、沙箱计算、测绘数据处理、四类水印、结果审核、只读结果输出、PostGIS、Elasticsearch、Kibana、ElastAlert2、FISCO BCOS、Sysmon和取证链条。

## 终端数量

生产环境按至少11台终端预留。终端数量由网络、认证和配置扩展，不在业务代码中写死。

## 环境差异

- 测试环境：允许两台测试电脑通过远程桌面连接两台服务器进行安装、调试和联调。
- 生产环境：终端和服务器接入甲方内网，按服务器1接收、服务器2只读输出的访问策略运行。
- 测试地址和生产地址必须通过配置切换。

## 当前不冻结的事项

以下内容要在甲方网络和真实数据确认后冻结：

- 服务器2结果接口是否通过HTTPS/TLS；
- 服务器区和终端区是否划分VLAN；
- DLG具体格式；
- FISCO BCOS四个逻辑节点的部署位置；
- GeoServer是否部署在服务器2或单独节点；
- 服务器2 1TB磁盘的原始、结果、临时和日志空间配额。
