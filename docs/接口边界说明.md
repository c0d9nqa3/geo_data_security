# 接口边界说明

## 终端到服务器1

服务器1是唯一数据接收入口。终端可调用：

- 登录和身份认证；
- 项目创建和项目查询；
- 数据上传；
- 处理任务提交；
- 任务状态查询；
- 审核申请和状态查询。

终端不可调用服务器1读取服务器2原始数据，也不可访问服务器1文件系统和数据库。

## 服务器1到服务器2

服务器1通过内部服务接口调用服务器2：

- 转交已校验数据；
- 创建处理任务；
- 查询任务状态；
- 查询结果索引；
- 发送审核和流转信息；
- 接收链上凭证和处理状态。

这类接口必须使用服务间认证，不允许把服务器2内部接口直接作为终端接口。

## 终端到服务器2

服务器2只开放结果输出接口：

- 下载指定的审核通过结果；
- 访问授权的GeoServer地图服务；
- 访问授权的OSGB/模型结果服务；
- 查询追溯记录和下载报告。

每次输出至少校验：用户身份、项目权限、结果ID、审核状态、授权令牌和有效期。

服务器2明确禁止：

- 终端上传原始数据；
- 目录列表；
- 通过路径下载任意文件；
- 访问原始数据；
- 访问VeraCrypt盘符；
- 访问数据库和管理端口。

## 配置切换

测试和生产环境只通过配置切换：

- `SERVER1_BASE_URL`；
- `SERVER2_INTERNAL_URL`；
- `SERVER2_READONLY_OUTPUT_URL`；
- `SERVER1_PORT`；
- `SERVER2_INTERNAL_PORT`；
- `SERVER2_READONLY_OUTPUT_PORT`。

代码中不得出现客户真实IP、密码、证书和密钥。
