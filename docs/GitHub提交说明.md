# GitHub提交说明

## 建议仓库名

`geo_data_security`

## 首次提交内容

首次提交只包含：

- 项目README；
- 架构说明；
- 服务器1和服务器2模块说明；
- 共享协议目录；
- 部署目录；
- 测试目录；
- 配置模板；
- Git忽略规则。

## 不应提交

- 客户真实数据；
- VeraCrypt加密卷文件；
- 数据库备份；
- Elasticsearch数据目录；
- FISCO BCOS私钥和证书；
- JWT密钥；
- 服务器真实IP和密码；
- 测试过程产生的大型Mesh或影像文件。

## 推荐提交顺序

1. 提交空工程架构和文档；
2. 提交共享数据模型和接口协议；
3. 提交服务器1最小接入服务；
4. 提交服务器2最小内部服务和只读结果接口；
5. 提交终端联调和权限测试；
6. 再逐步接入存储、沙箱、水印、审计和区块链。
