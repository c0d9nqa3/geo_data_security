# 项目研发工作说明（全项目）

## 一、项目脉络

建设测绘地理信息数据安全平台，覆盖数据"导入—处理—流转—审计"全生命周期。平台分两服务器部署于涉密网与政务网，两网各自闭环、统一程序，角色按配置启用。

**server1（接入/控制/审计展示）**：用户认证与权限、数据安全导入、任务下发与审批、流程控制、审计展示与告警。
**server2（处理/存储/只读输出）**：隔离环境内完成数据加工与水印嵌入，结果加密存储，仅向终端开放严格只读结果接口。
两机职责分离，任何一台不过载。

## 二、研发内容与功能

### 1. 数据沙箱安全计算
安全导入、处理行为受控（进程/文件/网络隔离）、加密计算与存储（VeraCrypt 卷）、几何精度降低、结果出箱审核、缓存残留清理。核心原则：只增标识、不改坐标拓扑。

### 2. 水印与流转追溯
数字水印覆盖 GeoTIFF 遥感影像、SHP/DLG 矢量、纹理与 Mesh 模型、独立专题矢量四类数据；FISCO BCOS 区块链存证：归属登记、流转登记、审计摘要上链；异常流转路径追踪、权限验证。

### 3. 审计与告警
任务级+操作级全链路审计；ES/Kibana 存储与展示（≥180天）；Sysmon 主机行为采集；异常告警（越权、批量下载、异常任务）目标 ≤10秒；≥100 并发审计能力。

### 4. 技术验证与部署
四类典型实景数据验收；Windows 服务化、开机自启；双网部署联调；性能实测（1GB SHP ≤10分钟、10GB Mesh ≤30分钟、水印嵌入成功率≥95%、常规处理后识别率≥90%）。
