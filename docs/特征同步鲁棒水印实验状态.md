# 特征同步鲁棒水印实验状态

## 已验证

- CPU版OpenCV 4.10.0.84已安装；
- SIFT在真实B1的裁剪、缩放和重投影变体上可找到匹配点；
- 特征匹配不是当前主要阻塞。

## 尚未通过

当前自写局部DCT特征载体在真实B1上不能稳定恢复32bit标识：

- 原图局部载体曾出现位错误；
- 裁剪、缩放、JPEG、噪声和滤波矩阵未通过；
- 尚未完成仿射归一化和纠错编码。

因此`feature_robust_watermark.py`仍属于实验模块，没有接入正式ProcessingService。

## 参考实现结论

- TrustMark官方实现使用100bit payload和BCH纠错，CPU可运行；
- TrustMark依赖PyTorch和模型文件，当前Windows开发环境安装未完成；
- TrustMark面向RGB自然图像，不能直接替代本项目要求的单波段GeoTIFF DWT+DCT+SVD方案；
- 论文中的经典DWT-DCT-SVD几何鲁棒方案采用多子图冗余、同步和纠错，后续正式改造应按这个结构实现。

## 当前判断

当前尚无证据证明特征同步版本达到“格式转换、裁剪、缩放后识别率≥90%”。在完成失败测试、仿射归一化、纠错编码和B1～B7完整矩阵前，不得标记为验收通过。
