# 成员2 进度核对报告（2026-09-04 终版）

对照：技术要求 (1)数据沙箱 (2)区块链+水印 (3)四类数据验证 (4)验收指标；
架构基线：server2=处理/存储/只读输出，server1=接入/控制。

## 一、已完成（真实运行验证，非声称）

### server2 处理链路（正式代码，非实验脚本）
- ProcessingService 统一分发：GeoJSON（属性水印+精度降低）、
  SHP/DLG 目录（每层加密属性水印，几何不变）、GeoTIFF（TrustMark 瓦片）、
  TEXTURES/OSGB（TrustMark 单码字）——失败自动清理结果目录
- /internal/tasks + 审核 + 只读下载全链，端到端测试覆盖（submit→approve→manifest→file）
- TrustMark 引擎：独立 venv 子进程桥（主 venv numpy2 与 torch 隔离），
  配置 GDS_TRUSTMARK_* 环境变量注入
- VeraCrypt 真实卷闭环：Adapter 全生命周期 + 处理结果落加密卷
- 审计：按天 JSONL 持久化 + API 全动作 + AUTH_DENIED

### 已有原始数据（磁盘复核）

当前 `data/` 目录只发现两类原始数据：

- **SHP/DLG 矢量**：9 个 SHP 图层（aanp、agnp、hyda、hydl、hydp、lrdl、lrrl、resa、resp）及 DBF/SHX/PRJ 等 sidecar；
- **遥感 GeoTIFF**：Landsat B1-B7 共 7 个 uint8 GeoTIFF 波段。

未发现独立的 GeoJSON、OSGB、OBJ、GLTF 或 GLB Mesh 数据。`LT..._VER.jpg` 是 Landsat 附属浏览图，不是倾斜 Mesh 纹理集。

### 两类已有数据的验证结果

| 已有类别 | 数据 | 验证 | 结果 |
|---|---|---|---|
| SHP/DLG 矢量 | 真实 9 层 SHP | 嵌入→提取，geometry digest 不变；SHP 重写和 SHP→GeoJSON 属性转换 | 9/9；转换抽样 3/3 ✅ |
| 遥感影像 | 真实 Landsat B1-B7（8111×7271） | TrustMark 瓦片引擎链，21 场景×7 波段 | 147/147 ✅ |

### 不能称为“真实数据已验证”的两类

- **二维专题矢量**：做过 SHP→GeoJSON 的格式转换链验证，但输入仍是同一批 SHP/DLG，不能算独立的二维专题矢量实景数据；暂无独立 GeoJSON 专题数据。
- **倾斜 Mesh**：只用 3 种程序生成的 photo-like 纹理验证了 TrustMark 纹理引擎的 JPEG/缩放/往返能力；没有真实 OSGB/Mesh 容器和真实纹理集，因此**倾斜 Mesh 未验证**。

### 鲁棒性实证（对照"格式转换、裁剪、缩放识别率≥90%"）
- 遥感 21 攻击场景：随机裁剪 25/75%、中心裁剪、缩放 25-125%、JPEG q90、PNG、
  噪声×3、高斯、中值、重投影 4326、删标签 = 147/147（100%）
- DLG 格式转换（SHP 重写 / SHP→GeoJSON）水印保持
- 纹理：JPEG 重压/缩放保持（TrustMark）；自写 DCT+SVD 基础版经实测在噪声纹理
  上不稳定（嵌入即 20/32 位），已如实降级为回退方案并在代码注释标注

## 二、差距（未完成/未实测，不夸大）

### 本机无法完成（部署环境依赖）
1. **Sysmon 未安装**（需管理员，本机 exit 1060）→ 主机行为采集缺失
2. **Elasticsearch/Kibana/ElastAlert2 未部署** → 180 天日志、≤10s 告警无法实测；
   审计已产出 JSONL，摄入 ES 留部署机
3. **PostGIS 未部署** → compute 模块（几何精度降低的数据库路径）未实连
4. **FISCO BCOS 无真实节点** → 区块链存证只到接口设计（server2/blockchain/README），
   交易上链未实测。真实节点需 Java 环境（本机无 Java/Maven）
5. **双网（涉密网/政务网）部署未做** → 需甲方网络环境，单机闭环只在本机
6. **VeraCrypt 卷大小**：当前 200MB 测试卷，验收性能测试需按数据规模扩卷

### 未实测的性能指标（验收(4)）
- 1GB SHP 导入处理 ≤10min：真实 DLG 仅 ~8MB 总量，未测 1GB
- 10GB Mesh ≤30min：无真实 OSGB 大模型
- ≥100 并发实时审计：审计写入未做并发压测（单线程 JSONL）
- 日志 ≥180 天：留存策略未部署（ES 层）
- 异常告警 ≤10s：ElastAlert2 未部署
- 水印嵌入成功率 ≥95%：遥感嵌入成功率 100%（147/147 嵌入无失败），
  四类整体嵌入成功率的官方口径统计未汇总（DLG/纹理均为确定性成功）

### 已知技术限制（如实）
- 纹理单码字模式不支持裁剪攻击（真实 OSGB 工作流不裁剪贴图；裁剪鲁棒需瓦片化，未做）
- 删标签+重投影组合（标签即原网格信息被删时无法自动逆投影）——需特征定位，未实现
- server1（Java）本机无 Maven/JDK，构建与联调未验证（属另一角色工作区）

## 三、结论

全链 API、加密卷存储、审计日志闭环也已有本机运行证据。二维专题矢量只有
