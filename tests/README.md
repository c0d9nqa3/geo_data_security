# tests：验证和验收测试目录

## 模块定位

本目录保存自动化测试、联调测试说明和验收测试记录。测试结果必须来自真实执行，不用预先填写的假数据代替。

## 计划目录

- `contract/`：服务器1、服务器2和终端接口契约测试。
- `security/`：越权、目录穿越、任意文件下载、任意任务执行和结果接口只读测试。
- `data_integrity/`：坐标、拓扑、投影、几何、顶点和文件哈希验证。
- `performance/`：1GB SHP、10GB Mesh和任务并发测试。
- `audit/`：Elasticsearch、FISCO BCOS、日志留存和告警测试。
- `deployment/`：两台服务器安装、启动、重启、备份和恢复测试。

## 验收指标

- 1GB SHP处理时间不超过10分钟；
- 10GB Mesh处理时间不超过30分钟；
- 水印嵌入成功率不低于95%；
- 常规处理后识别率不低于90%；
- 审计并发不低于100；
- 日志留存不少于180天；
- 告警时间不超过10秒；
- 四类数据在涉密网和政务网验证。
